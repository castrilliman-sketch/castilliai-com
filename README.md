# castilliai.com

Static site for Castilliai (NexusAI t/a CastilliAI), served by GitHub Pages from `main` (custom domain in `CNAME`).

- Shared styles: `assets/site.css`
- Site settings (MTD site link, contact email, waitlist endpoint): `assets/config.js`
- Pages: `/`, `/compliance-toolkit/`, `/about/`, `/founders-blog/`, `/privacy/`, `404.html`
- Old late-payment URLs (`/get-paid-uk/`, `/late-payment-calculator/`, `/free/`, `/posts/`) are redirect pages to `/`.
- The previous Get Paid Faster site is preserved at the git tag `archive-get-paid-faster`.

To add a Founders Blog post: copy `founders-blog/why-i-built-castilliai/` to a new folder, edit it, then add it to `founders-blog/index.html`, `sitemap.xml` and `llms.txt`.
